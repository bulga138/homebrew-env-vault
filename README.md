# homebrew-env-vault

Homebrew tap for [env-vault](https://github.com/bulga138/env-vault).

## Install

```bash
brew tap bulga138/env-vault
brew install --HEAD env-vault
```

Or directly:

```bash
brew install --HEAD bulga138/env-vault/env-vault
```

## Update

```bash
brew upgrade --fetch-HEAD env-vault
```
